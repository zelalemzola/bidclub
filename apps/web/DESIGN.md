# BidClub Web — Design System

## Product
Mobile-first sealed lowest-unique-bid arena (ETB). Luxury “win big” energy from BidClub hero art + modern floating nav (Instagram-like), without cloning competitors.

## Palette
- Night: `#0E0C0A`
- Charcoal: `#1A1714`
- Stone: `#F4F1EA`
- Paper: `#FFFFFF`
- Ink: `#14110E`
- Soft: `#5C564C`
- Mute: `#8F877A`
- Line: `#E6E0D6`
- Gold: `#C9A227`
- Gold bright: `#E0B83A`
- Danger: `#C0392B`
- Success: `#1A8F6A`

## Type
- Display: **Fraunces** (expressive, premium)
- Body: **Sora** (modern, mobile-clear)
- Mono: **IBM Plex Mono** (timers / sealed numbers)

## Radius
- Controls: `0.5rem`
- Cards: `0.75rem`
- Floating nav: full pill (`9999px`)
- Selected nav highlight: pill

## Floating nav
- Floats above bottom safe-area with horizontal margin
- Dark translucent pill bar
- White sliding selection pill (smooth transform)
- Width compresses slightly while scrolling down; expands when idle / scrolling up

## Signature
Hero celebration imagery + sealed mono bid vault + live HH:MM:SS countdown.
